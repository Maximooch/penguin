A few useful distinctions

A little clarity

Different tools.
Shared direction.

Is Link the same thing as Penguin?

No. Link is the shared workspace for people and agents. Penguin is our open-source coding agent. They’re separate products that can work together.

Do I have to use both?

No. Penguin can be used independently, and Link is built for other agents too. Visit the Link site for its current agent options.

Does this demo run a real agent?

No. The workspace and terminal are interactive illustrations. Tasks, changes, and checks are sample content. Feedback stays in this page’s memory and resets when you reload; it is not sent to a server. Nothing is merged or deployed.

What are you building toward?

We’re starting with Link and Penguin. Longer term, we plan to explore hosting and computing infrastructure for models and agents. That is a future direction, not an available infrastructure offering.
